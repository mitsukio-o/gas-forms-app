Privacy Policy — gas-forms

Effective: 2026-10-01

1. Who uses this app

gas-forms is a personal tool used only by its operator (GitHub user mitsukio-o) with the operator's own Google account. It is not offered to other users.

2. Google user data accessed

With the operator's authorization, the app uses these Google APIs / scopes:

  • Google Forms — create and edit forms, read form responses
  • Google Sheets — create response spreadsheets and link them to forms
  • Google Drive — move created forms and sheets into folders chosen by the operator
  • Apps Script — update and run the operator's own Apps Script project
  • Email address — confirm which account is signed in

3. How the data is used

Data is used only to carry out actions the operator explicitly requests: building forms, linking response sheets, and reading responses back to the operator. It is not used for advertising, profiling, or any other purpose.

4. Storage

The app has no server and no database. Forms, sheets, and responses stay in the operator's Google account. OAuth tokens are stored only on the operator's own computer.

5. Sharing

Google user data is not sold, rented, or shared with third parties. At the operator's direction, form content and responses may be processed by an AI assistant the operator uses to automate these tasks. That processing is limited to performing the requested task. The data is not used to develop, improve, or train generalized AI or machine-learning models.

6. Limited Use

gas-forms' use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

7. Revoking access and deletion

Access can be revoked at any time at myaccount.google.com/permissions. Revoking access invalidates the stored tokens. Forms and sheets created by the app are ordinary files in the operator's Google Drive and can be deleted there.

8. Contact

Questions about this policy: open an issue at github.com/mitsukio-o/gas-forms-app/issues.
